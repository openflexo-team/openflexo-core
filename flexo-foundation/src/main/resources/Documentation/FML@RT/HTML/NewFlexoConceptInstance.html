NewInstance

This edition primitive allows to dynamically instantiate a FlexoConceptInstance

Usage: 
[UndefinedFlexoConceptInstanceType(null) <value> =]
FML@RT::NewInstance(conceptType=<conceptType_path>[,options])
  • <conceptType_path> addresses a FlexoConcept
Configuration:
  • <conceptType_path> : FlexoConcept (required) - concept type to be instantiated
  • <args_path> : List (optional) - list of arguments
  • <container_path> : FlexoConceptInstance (optional) - container for newly created concept instance
Examples: 
myInstance = NewInstance(conceptType=aConceptType,container=object,arg0=anArgument);
Instantiate a new instance of concept referenced by ’aConceptType’ with supplied container and arguments, and assign this new instance to ‘myInstance’
