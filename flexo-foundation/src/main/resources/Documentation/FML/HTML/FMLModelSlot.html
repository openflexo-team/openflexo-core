FMLModelSlot

This ModelSlot represents access to a FML compilation unit
Such model slot allows reflective operations

Usage: 
[visibility] [cardinality] VirtualModel <identifier> with FML::FMLModelSlot([options]);
  • visibility is default (unspecified), public, protected or private
  • cardinality is [0,1] (unspecified), [0,*] or [1,*]
  • <identifier> is the name of declared model slot variable
Configuration:
  • <container_path> : Object (optional) -
  • <isReadOnly_path> : boolean (optional) -
  • <isRequired_path> : boolean (optional) -
Features:
  • Roles : FMLDataBindingRole FlexoConceptRole FlexoPropertyRole PrimitiveRoleRole FlexoConceptInstanceRoleRole FlexoBehaviourRole ActionSchemeRole
  • Edition actions : CreateFlexoConcept CreateTopLevelVirtualModel CreateContainedVirtualModel CreatePrimitiveRole CreateFlexoConceptInstanceRole CreateFlexoBehaviour
