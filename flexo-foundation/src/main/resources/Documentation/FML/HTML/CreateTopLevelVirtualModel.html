No documentation yet

Usage: 
[VirtualModel <value> =]
FML::CreateTopLevelVirtualModel(resourceName=<resourceName_path>,resourceCenter=<resourceCenter_path>,relativePath=<relativePath_path>[,options])
  • <resourceName_path> addresses a String
  • <resourceCenter_path> addresses a FlexoResourceCenter<? extends Object>
  • <relativePath_path> addresses a String
Configuration:
  • <resourceName_path> : String (required) - name for the resource to be created
  • <resourceCenter_path> : FlexoResourceCenter<? extends Object> (required) - ResourceCenter where the resource should be registered
  • <relativePath_path> : String (required) - relative path (relative to the resource center) where the resource should be created
  • <resourceURI_path> : String (optional) - URI for the resource to be created
