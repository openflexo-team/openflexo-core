## Usage

```java
[visibility] [cardinality] null <identifier> with PrimitiveRole([options]);
```

or

```java
[visibility] [cardinality] null <identifier> with FML@RT::PrimitiveRole([options]);
```

where

- `visibility` is default (unspecified), 'public', 'protected' or 'private'
- `cardinality` is \[0,1\] (unspecified), \[0,\*\] or \[1,\*\]
- \<identifier\> is the name of declared role variable
